# C++ Animated Walkthroughs | الرسوم المتحركة

This folder contains real, looping animated GIFs for the data structures in
the C++ project. Each file shows a small sequence of algorithm states; it is
an illustration, not a screen recording of the interactive program.

المجلد ده فيه ملفات GIF فعلية ومتكررة التشغيل لهياكل البيانات في مشروع C++.
كل صورة بتعرض حالات متتابعة لخوارزمية بمثال صغير؛ هي شرح توضيحي مش تسجيل
للبرنامج التفاعلي نفسه.
